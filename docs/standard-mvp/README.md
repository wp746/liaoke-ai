## 标准版 MVP 范围

标准版先跑通这条闭环：

1. 顾客扫桌码进入小程序。
2. 微信登录并自动成为门店会员。
3. 领取「今日吃肉券」。
4. 上传随手拍或输入一句话。
5. AI 生成朋友圈文案与增强图片。
6. 合成一张可保存海报。
7. 顾客自愿分享，海报二维码带邀请关系。
8. 新客扫码到店后绑定邀请关系。
9. 新客完成首次核销后，系统向邀请人发放次日生效的老带新抵扣券。
10. 服务员核销到店券、余额抵扣码或老带新抵扣券。
11. 商家后台看到扫码、发券、AI 使用、核销、新客、抵扣券、入群点击等数据。

顾客端体验中统一使用系统级 IP「燎小星」做轻量引导；线下桌牌可使用门店级 IP「AI × 小签」，牛里牛气试点为「AI 肉小签」。

## 暂不进入 MVP 的内容

- Seedance / 可灵 / 即梦视频生成。
- 多门店复杂连锁组织权限。
- 自动判断用户是否真的发朋友圈。
- 微信支付分账老带新返利。
- 复杂 CRM 自动化营销。
- 收银系统深度对接。

这些能力在 MVP 跑通后进入标准版 1.1 或高级版。

## 给开发方的默认技术假设

- 小程序：微信原生小程序或 Taro/uni-app 均可，但首版建议微信原生，减少兼容不确定性。
- 后端：Node.js/NestJS、Java/Spring Boot、Python/FastAPI 均可。本文接口以 REST JSON 表达。
- 数据库：MySQL 8.x。
- 缓存与锁：Redis。
- 文件存储：阿里云 OSS / 腾讯云 COS。
- AI 网关：后端统一封装，不允许小程序直连大模型密钥。
