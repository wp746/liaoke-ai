# 02 系统级 IP：燎小星

## 2.1 IP 名称

**燎小星**

## 2.2 一句话定位

> **燎小星是燎客 AI 的系统级 AI 小助手，一颗会说话的小火星，负责把顾客从扫码引导到领券、AI 晒圈、邀请奖励。**

## 2.3 命名逻辑

- **燎**：绑定燎客 AI，延续星火燎原的品牌意象。
- **小星**：一颗小火星、小星光，亲切、不压迫、适合出现在手机界面里。
- **燎小星**：不是冰冷客服，也不是单纯吉祥物，而是有引导能力的 AI 角色。

## 2.4 和门店级 IP 的关系

| 层级 | 名称 | 是否统一 | 出现位置 | 职责 |
|------|------|----------|----------|------|
| 系统级 IP | 燎小星 | 所有商家统一 | 小程序、海报角标、引导弹窗 | 接待、解释、引导、奖励提醒 |
| 门店级 IP | AI × 小签 | 每家店可定制 | 桌牌、菜单角标、店内海报 | 吸引扫码、制造好奇心 |

示例：

- 牛肉火锅店：AI 肉小签
- 咖啡馆：AI 咖小签
- 烧烤店：AI 串小签
- 酒馆：AI 酒小签

核心关系：

> **小签在桌上负责让顾客想扫，燎小星在手机里负责让顾客玩下去。**

## 2.5 IP 形象方向

### 基础形象

燎小星是一颗小火星，但不能做得太幼稚。

建议方向：

- 主体：小火星 / 小火苗 / 小星球的融合体。
- 轮廓：圆润、有亲和力。
- 标准服饰：固定使用金黄色小披肩/领巾，胸前保留星形识别点。
- 表情：聪明、热情、轻微调皮。
- 手部：可以有小手，用于举券、举海报、指向按钮。
- 光效：边缘有轻微火光或星光，体现「点燃」。

统一规则：

- 正式产品、小程序、PPT、销售物料里只使用「有披肩 3D 版」燎小星。
- 标准主形象必须是单独角色本体，不能带扫码机、手机、二维码、餐牌等周边物件。
- 头顶不要星星；胸前星形可以保留作为角色识别点。
- 无披肩旧 SVG 只作为早期概念源文件保留，不再作为对外主形象。
- 不同动作可以变，但头部火焰轮廓、圆脸、金黄色披肩、胸前星形必须保持一致。

### 视觉关键词

- 温暖
- 机灵
- 轻科技感
- 有烟火气
- 不儿童化
- 不二次元过重
- 不像传统客服头像

### 色彩建议

| 用途 | 色彩 |
|------|------|
| 主色 | 暖橙 / 火光橙 |
| 辅色 | 金黄 / 星光黄 |
| 科技点缀 | 少量蓝白光 |
| 禁用倾向 | 大面积冷蓝、黑金土豪风、幼儿卡通糖果色 |

## 2.6 性格设定

燎小星的性格是：

- 热情，但不吵。
- 聪明，但不卖弄。
- 会夸顾客，但不油腻。
- 帮商家做增长，但对顾客说人话。
- 像一个懂吃、懂拍照、懂朋友圈的小助手。

### 语气范例

可以说：

> 嗨，我是燎小星。先领一张今天的到店福利券，再一起玩 AI 晒圈吧。

> 券已经放进你的卡包啦，结账前给店员看一下就行。

> 传一张你刚拍的照片，说一句真实感受，剩下的交给我。

不要说：

> 亲，马上分享朋友圈即可获得裂变奖励！

> 系统检测到你具备转化价值，请完成传播动作。

> 尊敬的用户，请进入私域流量池。

## 2.7 标准动作状态

首版至少让设计师出 6 个状态：

| 状态 | 用途 |
|------|------|
| 欢迎 | 首页初次进入 |
| 举券 | 领券成功 |
| 思考 | AI 文案生成中 |
| 修图 | 图片增强中 |
| 举海报 | 海报生成成功 |
| 撒花 | 邀请成功 / 奖励到账 |

扩展状态：

- 睡觉：活动暂未开放。
- 着急：接口超时/稍后重试。
- 安慰：内容安全不通过，引导用户换图或改文案。

## 2.8 给设计师的简版 Brief

> 请为「燎客 AI / SparkFlow AI」设计系统级统一 IP 形象：**燎小星**。  
> 它是一颗会说话的小火星，是线下门店 AI 裂变获客系统里的官方 AI 小助手。  
> 形象需要温暖、机灵、有轻科技感，但不要幼稚，不要像传统客服头像。  
> 首版需要输出：基础站立形象 + 欢迎、举券、思考、修图、举海报、撒花 6 个动作状态。  
> 使用场景包括：微信小程序右下角悬浮头像、对话气泡、领券成功提示、AI生成中状态、海报生成成功弹窗、PPT品牌介绍页。
