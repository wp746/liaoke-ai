# 03 燎小星产品接入 PRD

> **视觉基线**：[`燎客跨端 Liquid Glass 视觉与动态系统`](../superpowers/specs/2026-07-12-liaoke-cross-platform-liquid-glass-visual-system.md)
> **实施契约**：[`小程序开发公司视觉实施与交接契约`](08-mini-program-development-handoff.md)
> 本文所有页面、触发和资产必须遵守上述锁定规范。

## 3.1 目标

把燎小星接入小程序，不是为了装饰，而是为了完成三件事：

1. 降低顾客理解成本：告诉顾客先领券、再玩 AI。
2. 提升玩法参与率：引导上传图片、输入一句话、保存海报。
3. 形成品牌记忆：让顾客记住燎客 AI，而不只是记住某家店的桌牌。

## 3.2 接入形式

统一形式：

- 页面 Hero：使用场景库中与业务一致的完整燎小星。
- 右下角悬浮头像和对话气泡：用于可主动召唤的助手能力。
- 特定动作状态图：用于领券、AI、积分、账户等不同语义。
- 关键成功、空、错误状态：必要时使用居中弹窗或状态页。
- 普通列表和右箭头区域：只使用低透明度局部暗纹，不重复堆叠完整角色。

层级规则：

- 悬浮头像高于普通内容。
- 低于支付、授权、核销二维码等关键弹窗。
- 用户手动关闭后，本会话不再自动弹欢迎类气泡。

## 3.3 页面级出现策略

| 页面 | 是否出现 | 形式 | 核心目的 |
|------|----------|------|----------|
| 首页 / 扫码落地页 | 是 | 右下角悬浮 + 欢迎气泡 | 解释先领券再玩 AI |
| 领券成功 | 是 | 举券状态 + 3 秒气泡 | 强化福利到账 |
| AI 玩法页 | 是 | 顶部引导气泡 / 思考状态 | 教顾客如何输入 |
| AI 结果页 | 是 | 修图/思考状态 | 降低等待焦虑 |
| 海报预览页 | 是 | 举海报状态弹窗 | 引导保存海报 |
| 我的券/我的页面 | 是 | 空态或奖励提醒 | 提醒奖励券 |
| 入群引导页 | 是 | 内嵌形象 | 解释入群福利 |
| 商家后台 | 是，低频 | 经营提醒、核销成功、空态 | 保持工具效率，同时延续品牌 |
| 平台后台 | 是，极低频 | 登录品牌、空态、关键引导 | 不进入密集表格和常规 CRUD |

### 3.3.1 场景库强制映射

| 页面语义 | 场景 ID | 资产要求 |
|------|------|------|
| 首页 / 到店欢迎 | `home-welcome` | 招手或欢迎道具 |
| 权益 / 券包 | `benefits-wallet` | 优惠钱包、券或红包语义 |
| AI 创作 | `ai-magic` | 星杖、魔法轨迹 |
| 积分 / 升级 | `points-reward` | 星币、奖励星点 |
| 我的 / 账户 / 服务 | `profile-phone` | 手机、账户管理语义 |

所有场景必须包含标准橙金披风，使用透明背景。顶部 Hero 统一使用 `170 × 170px` 视觉框，不得忽大忽小。

## 3.4 核心触发规则

### 首页首次进入

触发条件：

- 当前会话首次进入该门店首页。
- 用户未手动关闭过燎小星。

出现时机：

- 页面加载完成后 1-1.5 秒。

文案：

> 嗨，我是燎小星。  
> 先领一张今天的到店福利券，再一起玩 AI 晒圈吧。

按钮：

- 【去领券】
- 【先看看】

### 领券成功

触发条件：

- `/api/coupon/issue` 返回成功。

形象：

- 举券状态。

文案：

> 券已经放进你的卡包啦。  
> 结账前给店员看一下就行。

出现时长：

- 3 秒自动收起。

### AI 玩法页首次进入

触发条件：

- 当前会员首次进入 AI 玩法页，或本门店当天首次进入。

文案：

> 传一张你刚拍的照片，  
> 再说一句真实感受，  
> 我来帮你写成更高级的朋友圈。

### 文案生成中

触发条件：

- 调用 `/api/ai/text` 后等待中。

形象：

- 思考状态。

文案：

> 我在帮你想台词。  
> 让这顿饭看起来更值得被记住。

### 图片增强中

触发条件：

- 调用 `/api/ai/image` 后等待中。

形象：

- 修图状态。

文案：

> 我在帮这张照片提亮一点，  
> 让肉看起来更有食欲。

### 海报生成成功

触发条件：

- `/api/poster/generate` 成功。

形象：

- 举海报状态。

文案：

> 搞定。  
> 如果你愿意，可以保存这张海报，  
> 发到朋友圈或小红书做个记录。

按钮：

- 【保存到相册】
- 【知道了】

### 邀请奖励到账

触发条件：

- 新客首次核销后，邀请人奖励券发放成功。

文案：

> 你带来的朋友已经来吃啦。  
> 店里送你的奖励券已到账，下次记得用。

## 3.5 打扰控制

同一会话内：

- 自动弹出气泡不超过 2 次。
- 首页欢迎最多 1 次。
- AI 玩法引导最多 1 次。
- 领券成功、海报成功、奖励到账属于用户动作反馈，不计入自动弹出次数。

长期限制：

- 同一会员同一门店，每天最多自动欢迎 1 次。
- 同一会员同一门店，AI 玩法引导 7 天内最多出现 2 次。


## 3.8 前端验收标准

- 所有 C 端核心页面保持同一角色身份，但动作和道具必须随场景变化。
- 燎小星必须有披风、无白底、比例正确。
- 顶部 Hero 统一使用 `170 × 170px` 视觉框。
- 权益券卡与“我的服务”右箭头下方使用不影响阅读的低透明度燎小星暗纹。
- 关闭后不反复弹出。
- 加载中状态不遮挡主按钮。
- 海报页弹窗不影响保存相册。
- 弱网下 IP 图片加载失败时，降级为文字气泡或默认图标。
- iOS 与 Android 使用相同素材、布局、尺寸和动效参数。
- 所有新增、删除、修改、查询页面必须继承锁定的视觉 Token、共享组件和验收门槛。
