# 03 燎小星产品接入 PRD

## 3.1 目标

把燎小星接入小程序，不是为了装饰，而是为了完成三件事：

1. 降低顾客理解成本：告诉顾客先领券、再玩 AI。
2. 提升玩法参与率：引导上传图片、输入一句话、保存海报。
3. 形成品牌记忆：让顾客记住燎客 AI，而不只是记住某家店的桌牌。

## 3.2 接入形式

统一形式：

- 右下角悬浮头像。
- 对话气泡。
- 特定动作状态图。
- 必要时使用居中弹窗。

层级规则：

- 悬浮头像高于普通内容。
- 低于支付、授权、核销二维码等关键弹窗。
- 用户手动关闭后，本会话不再自动弹欢迎类气泡。

## 3.3 页面级出现策略

| 页面 | 是否出现 | 形式 | 核心目的 |
|------|----------|------|----------|
| 首页 / 扫码落地页 | 是 | 右下角悬浮 + 欢迎气泡 | 解释先领券再玩 AI |
| 领券成功 | 是 | 举券状态 + 3 秒气泡 | 强化福利到账 |
| AI 玩法页 | 是 | 顶部引导气泡 / 思考状态 | 教顾客如何输入 |
| AI 结果页 | 是 | 修图/思考状态 | 降低等待焦虑 |
| 海报预览页 | 是 | 举海报状态弹窗 | 引导保存海报 |
| 我的券/我的页面 | 是 | 空态或奖励提醒 | 提醒奖励券 |
| 入群引导页 | 是 | 内嵌形象 | 解释入群福利 |
| 商家后台 | 否 | 不出现 | 商家端保持工具效率 |

## 3.4 核心触发规则

### 首页首次进入

触发条件：

- 当前会话首次进入该门店首页。
- 用户未手动关闭过燎小星。

出现时机：

- 页面加载完成后 1-1.5 秒。

文案：

> 嗨，我是燎小星。  
> 先领一张今天的到店福利券，再一起玩 AI 晒圈吧。

按钮：

- 【去领券】
- 【先看看】

### 领券成功

触发条件：

- `/api/coupon/issue` 返回成功。

形象：

- 举券状态。

文案：

> 券已经放进你的卡包啦。  
> 结账前给店员看一下就行。

出现时长：

- 3 秒自动收起。

### AI 玩法页首次进入

触发条件：

- 当前会员首次进入 AI 玩法页，或本门店当天首次进入。

文案：

> 传一张你刚拍的照片，  
> 再说一句真实感受，  
> 我来帮你写成更高级的朋友圈。

### 文案生成中

触发条件：

- 调用 `/api/ai/text` 后等待中。

形象：

- 思考状态。

文案：

> 我在帮你想台词。  
> 让这顿饭看起来更值得被记住。

### 图片增强中

触发条件：

- 调用 `/api/ai/image` 后等待中。

形象：

- 修图状态。

文案：

> 我在帮这张照片提亮一点，  
> 让肉看起来更有食欲。

### 海报生成成功

触发条件：

- `/api/poster/generate` 成功。

形象：

- 举海报状态。

文案：

> 搞定。  
> 如果你愿意，可以保存这张海报，  
> 发到朋友圈或小红书做个记录。

按钮：

- 【保存到相册】
- 【知道了】

### 邀请奖励到账

触发条件：

- 新客首次核销后，邀请人奖励券发放成功。

文案：

> 你带来的朋友已经来吃啦。  
> 店里送你的奖励券已到账，下次记得用。

## 3.5 打扰控制

同一会话内：

- 自动弹出气泡不超过 2 次。
- 首页欢迎最多 1 次。
- AI 玩法引导最多 1 次。
- 领券成功、海报成功、奖励到账属于用户动作反馈，不计入自动弹出次数。

长期限制：

- 同一会员同一门店，每天最多自动欢迎 1 次。
- 同一会员同一门店，AI 玩法引导 7 天内最多出现 2 次。

## 3.7 埋点事件

| 事件名 | 触发 |
|--------|------|
| `ip_show` | 燎小星展示 |
| `ip_click` | 用户点击燎小星 |
| `ip_close` | 用户关闭气泡 |
| `ip_cta_click` | 用户点击燎小星气泡按钮 |
| `ip_reward_notice_show` | 奖励到账提示展示 |

事件字段：

```json
{
  "store_id": "STORE001",
  "member_id": "MEM202606270001",
  "page": "home",
  "ip_state": "welcome",
  "copy_key": "home_welcome",
  "session_id": "sess_xxx"
}
```

## 3.8 前端验收标准

- 所有 C 端核心页面燎小星样式统一。
- 关闭后不反复弹出。
- 加载中状态不遮挡主按钮。
- 海报页弹窗不影响保存相册。
- 弱网下 IP 图片加载失败时，降级为文字气泡或默认图标。
