# 燎客 AI 品牌与 IP 文档包

本目录用于沉淀「AI 扫码牌」项目的品牌体系、系统级 IP、门店级桌牌 IP，以及对外 PPT / 官网 / 朋友圈可直接使用的话术。

## 文档清单

- `01-brand-system.md`：燎客 AI / SparkFlow AI 的品牌定位、命名体系、Slogan、使用规范。
- `02-liaoxiaoxing-ip.md`：系统级统一 IP「燎小星」的角色定位、形象设定、性格、动作状态。
- `03-product-integration-prd.md`：燎小星在小程序里的接入规则、页面出现策略、文案和打扰控制。
- `04-ppt-and-sales-copy.md`：一页 IP 体系 PPT 文案、销售 pitch 话术、朋友圈/官网短文案。
- `05-visual-identity-system.md`：第一版 Logo、色彩、字体、组件、桌牌视觉规范。
- `06-brand-asset-package.md`：正式品牌资产包索引、导出命令、交付清单。
- `07-liaoxiaoxing-asset-pack.md`：燎小星首版形象资产包索引、使用场景、精修清单。
- `08-mini-program-development-handoff.md`：交给小程序开发公司的视觉实施、真机交付与验收契约。
- `../superpowers/specs/2026-07-12-liaoke-cross-platform-liquid-glass-visual-system.md`：三端正式锁定的视觉与动态治理标准。

## 已锁定的视觉基线

从 2026-07-12 起，用户端、商家端和平台后台统一使用“橙金暖白 Liquid Glass + Fluent Acrylic + 场景化燎小星”系统。以后任何新增、删除、修改、查询模块均必须沿用同一套 Token、共享组件、场景库和验收门槛；不得按单页重新设计。

## 最终命名结构

| 层级 | 名称 | 用途 |
|------|------|------|
| 系统中文主品牌 | 燎客 AI | 对商家、对外方案、官网、PPT |
| 系统英文名 | SparkFlow AI | 英文物料、域名、Pitch Deck |
| 系统级统一 IP | 燎小星 | 小程序内统一 AI 小助手 |
| 门店级桌牌 IP | AI × 小签 | 每家店线下桌牌定制名，如 AI 肉小签 |

## 一句话结构

> 桌上是每家店自己的 AI 小签，手机里是全系统统一的燎小星：  
> 小签负责把人拉进来，燎小星负责把人点燃。
