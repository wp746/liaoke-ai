# 燎客成本支出、利润控制与商家算账板 v3.1

> 版本：v1.0  
> 产品版本：燎客 AI v3.1  
> 使用对象：创始人、财务、销售负责人、客户成功负责人、融资/路演材料编写者

## 1. 先把账分成两套

燎客要同时算两套账：

1. 给商家看的账：用了燎客以后，门店多了多少扫码、核销、复购、新客和可感知收入。
2. 公司自己的账：每签一家店，公司收入多少、成本多少、毛利多少、交付多久回本。

不能把两套账混着讲。商家只关心“我花钱值不值”；公司内部必须关心“这单赚不赚钱”。

## 2. 收入模型

建议标准套餐：

| 收入项 | 建议价格 | 说明 |
|---|---:|---|
| 试点期 | 0-1999 元 | 可按城市和商家规模决定是否收部署保证金 |
| 首次部署费 | 1999-4999 元/店 | 桌码配置、物料、培训、上线服务 |
| SaaS 月费 | 699-1999 元/店/月 | 单店标准版 |
| SaaS 年费 | 6990-19900 元/店/年 | 建议年付优惠 1-2 个月 |
| 运营增值包 | 999-4999 元/月 | 月报、活动、节日营销、培训 |
| 连锁品牌版 | 2999-9999 元/月 | 多门店看板、品牌活动、总部报表 |

早期建议：

- 单店试点标价：首月免费或收 999 元部署保证金。
- 正式版：699 元/月起，不要低于 499 元/月，否则客户成功成本覆盖不了。
- 年付：6990 元/年起，送桌牌物料和一次复盘会。

## 3. 单店成本结构

### 一次性成本

| 成本项 | 建议估算 | 说明 |
|---|---:|---|
| 桌牌设计与打印 | 150-500 元/店 | 视桌数和材质 |
| 门店配置 | 100-300 元/店 | 运营人力折算 |
| 老板培训 | 100-300 元/店 | 线上低，线下高 |
| 店员培训 | 100-500 元/店 | 到店培训计交通和时间 |
| 销售获客 | 200-1500 元/店 | BD 拜访、渠道返佣、样品 |

### 月度持续成本

| 成本项 | 建议估算 | 控制方式 |
|---|---:|---|
| 云服务器与数据库 | 20-100 元/店/月 | 多店共用后摊薄 |
| AI 文案/图片调用 | 20-150 元/店/月 | 每人每日次数上限、超额预警 |
| 短信/订阅消息/通知 | 5-30 元/店/月 | 优先微信订阅消息 |
| 客户成功人力 | 100-500 元/店/月 | SOP、批量周报、自助后台 |
| 售后与故障 | 20-100 元/店/月 | 标准化 FAQ 和监控 |

## 4. 单店毛利模型

### 保守模型

| 项目 | 金额 |
|---|---:|
| 月费收入 | 699 |
| 云资源摊销 | -50 |
| AI 调用 | -80 |
| 客户成功人力 | -250 |
| 售后与通知 | -40 |
| 单店月毛利 | 279 |
| 毛利率 | 39.9% |

这个模型说明：如果只收 699 元/月，而且客户成功靠人盯，毛利不高。所以前 20 家可以为了验证接受，但不能长期靠人工服务撑。

### 标准模型

| 项目 | 金额 |
|---|---:|
| 月费收入 | 1299 |
| 云资源摊销 | -40 |
| AI 调用 | -80 |
| 客户成功人力 | -180 |
| 售后与通知 | -30 |
| 单店月毛利 | 969 |
| 毛利率 | 74.6% |

### 增值模型

| 项目 | 金额 |
|---|---:|
| SaaS 月费 | 1299 |
| 运营增值包 | 1999 |
| 总收入 | 3298 |
| 云资源 + AI | -150 |
| 客户成功 + 运营人力 | -700 |
| 设计模板摊销 | -100 |
| 单店月毛利 | 2348 |
| 毛利率 | 71.2% |

结论：

- 只卖软件，靠规模赚钱。
- 软件 + 运营增值，靠服务能力赚钱。
- 早期最现实的是混合模式：标准 SaaS 保底，重点商家加运营包。

## 5. 给商家算账版

以一个火锅店为例：

- 日均 40 桌。
- 每桌 3 人。
- 人均 80 元。
- 月营业 25 天。

基础客流：

| 项目 | 计算 | 结果 |
|---|---|---:|
| 日到店人数 | 40 桌 x 3 人 | 120 人 |
| 月到店人数 | 120 人 x 25 天 | 3000 人 |
| 月基础营业额 | 3000 人 x 80 元 | 240000 元 |

燎客带来的新增链路：

| 环节 | 保守假设 | 结果 |
|---|---:|---:|
| 扫码率 | 35% | 1050 人/月 |
| 领券率 | 扫码用户 80% | 840 人/月 |
| AI 晒圈率 | 扫码用户 20% | 210 人/月 |
| 老带新新客 | 每 4 个晒圈带 1 个新客 | 52 人/月 |
| 新客消费 | 52 人 x 80 元 | 4160 元/月 |
| 新客二次复购 | 25% | 13 人 |
| 二次复购收入 | 13 人 x 80 元 | 1040 元 |
| 月直接可见新增 | 新客 + 二次复购 | 5200 元 |

给老板的话术：

> 你不是花 699 买一个小程序，你是在把每个月已经进店的 3000 个人变成可沉淀、可触达、可复购、可转介绍的人。只要每月多带来 10 个新客，按人均 80 元就是 800 元，月费就覆盖了；如果能带来 50 个新客，就是 4000 元以上新增消费。

## 6. 商家成本感知解释

商家会怕什么：

- 怕券发太多亏钱。
- 怕员工不会操作。
- 怕顾客薅羊毛。
- 怕系统复杂没人用。
- 怕花钱看不到效果。

对应解释：

| 商家担心 | 燎客解释 |
|---|---|
| 券发太多 | 老带新抵扣券有面值、门槛、有效期、月上限 |
| 积分亏钱 | 积分只能换赠品/服务，不能抵现金 |
| 员工不会 | 店员只记一句话：扫这个码有券，还能 AI 做朋友圈大片 |
| 被薅羊毛 | 同人同日限制、核销幂等、异常告警 |
| 看不到效果 | 每周给扫码、核销、AI 晒圈、新客、积分兑换数据 |

## 7. 公司现金流控制线

### 0-20 家门店

目标：验证。

| 指标 | 控制线 |
|---|---:|
| 每月固定支出 | 不超过 5-8 万 |
| 人员 | 4-7 人 |
| 技术支出 | 外包为主，关键验收自控 |
| 单店交付时间 | 不超过 3 天 |
| 现金储备 | 至少 6 个月 |

不建议：

- 租大办公室。
- 过早招全职设计、HR、品牌。
- 为单个商家做深度定制。

### 20-100 家门店

目标：复制。

| 指标 | 控制线 |
|---|---:|
| 每月固定支出 | 不超过 MRR 的 70% |
| 单店毛利率 | 60% 以上 |
| 客户成功人效 | 1 人管理 20-40 家店 |
| 销售获客成本回收 | 3 个月内 |
| 年付占比 | 30% 以上 |

### 100 家以上

目标：规模化。

| 指标 | 控制线 |
|---|---:|
| MRR | 稳定覆盖团队固定成本 |
| 净收入留存 NRR | 100% 以上 |
| 月流失率 | 3% 以下 |
| 自助配置占比 | 50% 以上 |
| 渠道订单坏账率 | 5% 以下 |

## 8. 利润分配建议

只要公司还没稳定盈利，不建议大额分红。

### 早期有利润时

| 用途 | 建议比例 |
|---|---:|
| 产品研发与稳定性 | 30% |
| 销售获客 | 25% |
| 客户成功与培训 | 20% |
| 现金储备 | 15% |
| 创始团队奖金 | 10% |

### 进入稳定盈利后

| 用途 | 建议比例 |
|---|---:|
| 产品研发 | 25% |
| 市场销售 | 25% |
| 客户成功 | 15% |
| 现金储备 | 15% |
| 团队奖金/期权池 | 10% |
| 股东分红 | 10% |

## 9. 什么时候可以扩大规模

不要按“签了多少家”扩张，要按“单位模型是否成立”扩张。

可以扩张的条件：

- 至少 20 家付费门店。
- 连续 2 个月续费率不低于 80%。
- 单店毛利率不低于 60%。
- 销售获客成本 3 个月内能回收。
- 客户成功 1 人可以稳定服务 20 家以上门店。
- P0 故障 30 天为 0。

未满足时不要扩张：

- 签了很多试点，但转正式少。
- 商家要靠创始人天天盯才用。
- 每家店都要定制。
- 客服和运营被小问题拖死。

## 10. 独立 App 的判断

v3.1 后不要急着做独立 App。小程序更适合餐饮堂食扫码场景。

可以考虑 App 的条件：

- 有 500+ 门店或 50 万+ C 端用户。
- 用户有跨店消费、积分权益、会员身份沉淀需求。
- 商家端后台需要更复杂的经营分析。
- 有足够预算做 App 获客、安装、留存。

优先顺序：

1. 小程序稳定。
2. 商家 Web 后台完善。
3. 连锁品牌后台。
4. 城市/渠道后台。
5. 最后再考虑独立 App。
