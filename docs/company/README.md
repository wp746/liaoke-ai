# 燎客公司化经营文件包

> 版本：v1.0  
> 适用阶段：燎客 AI v3.1 产品进入开发交付、试点招商、初始团队搭建阶段  
> 使用对象：创始人、合伙人、招聘候选人、外包开发公司、法务/律师、财务顾问

## 文件清单

- `01-organization-roles-and-headcount.md`：公司架构、阶段编制、岗位职责与岗位边界。
- `02-compensation-and-kpi-standards.md`：薪资标准、提成规则、绩效考核、淘汰和晋升机制。
- `03-contract-compliance-constraints.md`：员工、合伙人、商家、外包、渠道合同的关键约束清单。

## 使用原则

燎客现在不能按“大公司”方式堆部门。早期真正要管住的是三件事：

1. 产品能上线，数据能跑通。
2. 商家愿意付费续约。
3. 团队不会因为口头承诺、职责不清、提成乱算把公司拖死。

所以本文件包采用“三阶段组织”：

- 0-20 家门店：创始人强管，少人高密度。
- 20-100 家门店：岗位专业化，建立销售、交付、客户成功、产品技术的基本分工。
- 100 家以上：区域化与平台化，开始建立中台和标准培训体系。

## 重要声明

薪资区间为初创 SaaS/本地生活服务公司的建议标准，需根据所在城市、社保基数、候选人能力、试用期表现调整。合同条款不是律师正式合同文本，只是你交给律师定稿前的业务约束清单。
