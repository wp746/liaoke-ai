# 燎客成熟公司与成熟产品交付物路线图

> 版本：v1.0  
> 目标：把“燎客公司 + 燎客产品”拆成可逐步交付的一整套经营、培训、招商、融资和开发文件

## 第一批：公司化治理文件（已先做）

- 公司架构、岗位职责与阶段编制。
- 薪资、提成、绩效、晋升淘汰。
- 合同体系与法务约束。
- 成本支出、利润控制、商家算账板。
- 系统运行逻辑与升级路线。

## 第二批：培训手册

建议拆成 4 份，而不是混成一本：

1. 员工培训版手册：给燎客内部销售、运营、客户成功。
2. 商家老板培训版手册：给老板讲商业价值、成本、数据、续费。
3. 店员培训版手册：只讲一句话话术、扫码引导、核销操作、常见问题。
4. 开发/交付培训版手册：给开发公司、实施人员、测试人员。

当前进度：全角色主说明书已经完成，见 `docs/operations/liaoke-complete-system-manual-v3.1.md`。后续四份培训版手册应从主说明书按受众抽取和精简，不重新发明业务规则。

## 第三批：PPT

建议拆成 4 套：

1. 路演版 PPT：融资、资本、政府场景，讲市场、产品、商业模式、团队、财务预测。
2. 招商版 PPT：给商家、渠道、城市合伙人，讲赚钱逻辑、案例、套餐、合作政策。
3. 政府资本汇报 PPT：讲数字经济、餐饮复苏、就业、消费、数据合规。
4. 商家成交 PPT：给单店老板，讲痛点、演示、算账、试点方案。

## 第四批：产品与开发文件

现有基础：

- PRD v3.0。
- 积分模块 v3.1。
- 数据库 SQL。
- API 文档。
- 原型页面。
- 验收标准。

后续建议补：

- PRD v3.1 整合总版：把 v3.0 和积分 v3.1 合成一份完整 PRD。
- v3.2 需求池：核销撤销、商家月报、积分提醒、A/B 测试。
- 运营后台 PRD：合同、套餐、续费、数据导出、风险告警。

## 第五批：经营仪表盘

建议输出为表格或后续做成后台：

- 销售漏斗板。
- 门店上线进度板。
- 单店经营效果板。
- 客户成功续费风险板。
- 成本利润控制板。
- AI 成本与调用量控制板。

## 推荐交付顺序

1. 先定公司架构和岗位绩效，不然招来的人不知道怎么干。
2. 再做培训手册，不然销售、运营、店员讲法不统一。
3. 再做 PPT，不然路演、招商会变成临场发挥。
4. 最后做完整 PRD 整合总版和 v3.2 需求池，交给开发公司继续迭代。
