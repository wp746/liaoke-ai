# 燎小星场景库

场景库用于保证燎小星在不同业务任务中保持同一角色身份，同时通过动作、表情和道具表达不同语义。

## 当前场景

| 场景 | 业务语义 | 关键道具 | 资产 |
| --- | --- | --- | --- |
| 首页欢迎 | 到店、开始体验 | 餐厅欢迎牌 | `scene-home-welcome-transparent-v1.png` |
| 权益钱包 | 福利、领券、核销 | 优惠钱包、星券 | `scene-benefits-wallet-transparent-v1.png` |
| AI 魔法 | 上传、生成、完成 | 星杖、魔法轨迹 | `scene-ai-magic-transparent-v1.png` |
| 积分奖励 | 积分、任务、升级 | 星币、奖励星点 | `scene-points-reward-transparent-v1.png` |
| 会员账户 | 资料、作品、设置 | 手机、标准披风 | `scene-profile-phone-cape-transparent-v2.png` |

## 使用规则

- 页面 Hero、关键成功状态和 AI 引导可以使用完整角色。
- 普通列表与高频按钮使用火焰、星点、尾焰和液滴等局部符号，不重复摆放完整角色。
- 同一页面只保留一个主要角色动作，避免多个完整燎小星争抢注意力。
- 标准身份必须包含：火焰轮廓、五官比例、领结、胸前星标、手套鞋子和橙金披风；任一场景不得遗漏披风。
- 顶部 Hero 使用统一 `170 × 170px` 角色视觉框；下方功能卡和列表暗纹可以缩小。
- iOS 与 Android 使用同一透明 PNG、尺寸比例和动效时长。
- 场景素材必须保留透明背景，不允许用白色矩形或整张场景图覆盖玻璃容器。
- 根目录 PNG 是高清母版；`display/` 目录是界面运行用轻量版本，最长边控制为 600px。
